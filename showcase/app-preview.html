4 · Rules this file enforces

Sizes

  • Idle 200×36
  • Hover 260×40
  • Open 360×460
  • Pill radius 999px
  • Panel radius 18px

Colour

  • Accent #FFAA00
  • Danger #EF4444
  • Dark shell rgba(18,19,22,.92)
  • Light shell rgba(255,255,255,.92)
  • No third accent

Type

  • Inter, vendored locally
  • Title 13 / 600
  • Artist 11 / 400
  • Timer 15 / 600 tnum
  • Panel timer 40 / 600 tnum

Icons

  • Lucide, 18px pill
  • 14px inside tabs and buttons
  • 1.6px stroke, rounded
  • Inlined SVG, no runtime dep
  • Emoji are banned

Motion

  • Hover fade 120ms
  • Resize 150ms
  • Ease cubic-bezier(.22,1,.36,1)
  • No bounce except mascot

Materials

  • Pill: transparent CSS capsule
  • No Windows acrylic on the pill
  • Acrylic ignores CSS radius (tested)
  • Blur would need native shaping
