## 1. What this is
Beam is an offline Windows 11 floating pill that gives 1-click media controls, a file drop shelf, a countdown timer, and a month calendar. No cloud, no accounts, no network.

**Current (2026-11-02):** the app runs one 136×42 window holding a 94×30 capsule (24px star at 70% opacity when idle) and owns a live `BeamBridge.exe` child over stdio JSON lines. The helper reports the system's current media session (`music.changed`: app, title, artist, album, playing, position, duration, and the artwork as a base64 PNG), puts real file paths on the clipboard as `CF_HDROP`, and watches the foreground window for fullscreen (`fullscreen.changed { active }`, plus a `fullscreen.get` probe); main wraps the base64 art as a data URL, pushes `beam:music:state`, and the pill shows the live track title, 24px art, and a green/amber dot (a null session is held 500ms across Spotify's between-track gap; a missing-file red dot wins), hides the pill while a fullscreen window owns the monitor, and the tray click shows it again. On hover the pill swaps the title for prev / play-pause / next; each button sends `beam:music:command`, main calls the helper, and the helper drives the live SMTC session (a refusal only logs). The panel's Music tab shows the live track's 148px art, title, artist, a read-only position bar that starts at the last SMTC position and advances on a local 1s tick, and the same three transports; the tab's play/pause drives the same command path, and the tab makes no network requests. Files dropped on the pill are read with `webUtils.getPathForFile`, held as paths in main memory (deduped, 50 cap), and the pill reads `N files` (or `Max 50` after an overflowing drop). Opening the panel pushes each shelf path's stat row (name, size, folder/file, missing) to the renderer, so the Files tab renders the real list; Copy All and each row's copy button call `beam:files:copy`, main accepts only shelf paths, and the helper writes them as `CF_HDROP`. Each existing row is also draggable: a row's `dragstart` calls `beam:files:drag`, main re-checks the path against the shelf and disk, then hands it to `webContents.startDrag`; the pill itself still moves the window. A panel open that fails a stat marks the row `Missing` (tooltip `File moved or deleted`) with no copy or drag, and gives the pill's star a red danger pip until a later open finds every file again. A row's × removes its path and the armed Clear All empties the shelf; both reply with fresh rows, so the tab re-renders and the pill returns to `Beam` at zero, while an 11px `Files clear on quit` note sits beside the actions only while rows exist. Music, timer, and done will rest at 94 and grow to 128 on hover inside the same window, while idle and files stay 94. ## 2. Stack
- Electron + TypeScript + Vite, exact-pinned. Renderer sandboxed, contextIsolation on, nodeIntegration off. The renderer is vanilla TypeScript with shadcn-style tokens and Lucide; no React or Tailwind.
- `native/BeamBridge/` — windowless C# .NET 10 helper, self-contained single-file publish. Owns SMTC, clipboard, and fullscreen detection (all built; fullscreen is proved by verify check 14 with a real borderless window). Drag-out is app-owned and built at 3.4: the renderer's `dragstart` on a Files row goes to main, which calls `webContents.startDrag` with the real paths.
- No database, no server, no TCP ports. Main ⇄ helper is stdio JSON lines only.
- Settings live in `%APPDATA%\Beam\settings.json`.

## 8. Gotchas & Known Traps
- `Alt+Space` is the planned hotkey (task 1.8) and will steal the system window menu while Beam runs. Accepted by the user; fall back to `Ctrl+Shift+Space` if registration fails.
- Global hotkey and tray depend on the window never taking foreground on show.
- Timer counts from a deadline timestamp, never by decrementing. Sleep must not break it.
- Shelf is wiped on quit by design, and must warn while non-empty.
- Fullscreen hide needs the helper alive; the hotkey is main-owned. Helper restart logic is max 3 times in 60s.
- With a track active, verify prints SKIP for idle dim, drop pill labels, clear pill labels, and the restart pill label; those facts are asserted from `[files]` logs and `capsule.css` instead. The strict pill-label path needs no media session. The music pill's transports call SMTC through the helper; verify check 22 pauses/plays and skips real tracks, and check 23 then toggles playback twice from the Music tab, so a run disturbs playback. The artwork now travels as base64 inside `music.changed` (2026-11-04), so the old `%TEMP%\Beam\art` file race is gone; no art in the session shows the 48px star face.
- CDP `Input.dispatchDragEvent` is broken with Electron 45: every type arrives as a `dragenter` (measured 9 enters, 0 dragover, 0 drop across three dispatches), so check 16 cannot land a synthetic drop and the UI probe fills the shelf through `window.beam.addFiles`. A real OS drag is the honest replacement. `.pill` is pinned to 30px because Windows hands the window a 44 DIP content height; without the pin it rendered 32.
- Every state rests at 94 inside the 136 window, so 21px of transparent margin on each side receives clicks (hover states leave 4px). This is still unfixed: a click in that margin opens the panel instead of reaching the window underneath. No task owns it yet.
- Move the window with `setBounds` and a pinned width/height. `setPosition` let Windows re-round the transparent window's height on every pointer move (42 grew to 141 during the first 1.4 test). The window's settled outer bounds are 136×45 at 125%, with a 136×44 content rect; keep that size while dragging.
- The saved position is the window's outer top-left plus `displayId`. Restore only when that rect still intersects a current display; otherwise anchor on the primary display. Multi-monitor and 100/150% scaling remain unproven.
- Electron RAM is the top project risk. Idle at 136×42 with the panel and tray installed (2026-10-29): 99 MB private summed across 5 processes — main 33.4, renderer 28.1, gpu-process 15.0, utility 11.7, helper 10.8 — and 0.2% CPU, under the 130 MB gate. The helper is also gated separately at 60 MB.
