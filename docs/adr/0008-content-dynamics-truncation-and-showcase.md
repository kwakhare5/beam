# Content dynamics, middle-truncation, and the unified showcase board

Status: accepted; amended 2026-10-28 by ADR-0009, which fixed the title slot, removed the missing-file capsule state, and restored standard sentence casing, by the 100/136 pass, which set the music title slot to 50px at rest and 86px on hover, and by the 100-rest pass, which made every state rest at 100 and show one fact.

The resting capsule shows one fact in a 50px slot: the track title, timer digits, a done check, or a file count. On hover or focus the three states with more to show grow to 136: music fades the star and title for transports, timer adds a 28px cancel after its digits (slot 86), and done replaces its check with `Done` and a 28px dismiss. Idle and files keep the same content and width. Nothing jumps and long titles ellipsize. Filenames in shelf rows middle-truncate at 26 characters (`quarterl…inal.xlsx`) so the prefix and extension survive. The shelf capsule shows only a count, with a red mascot pip when a file is missing; the row carries the `Missing` badge and the full name. When a timer and background music run together, the timer owns the capsule (`Focus` plus digits) and a 6px gold media pip marks playback. Copy uses standard sentence case. The default preview page is the unified Showcase Board, and it uses one data set for every capsule and panel so counts, timers, and file names agree.
