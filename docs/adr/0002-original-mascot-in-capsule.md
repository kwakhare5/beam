# The capsule uses the original master mark

A custom 20px mini mark replaced the Puffy Chubby Star in the capsule. That was rejected: the mascot is the brand. The capsule now uses the original `beam-mascot.svg` at 24px; the state mascots (`star-music`, `star-files`) remain at 48px in the music and files empty states. The `assets/mascot/` files are unchanged. Content state is conveyed by the line, digits, and border tone, not by swapping the capsule mascot.
